Entry for the [make.fun](https://make.fun) competition **Notes From a Passive-Aggressive Fridge** (#195): one funny passive-aggressive note a smart fridge leaves for its owner.

## The entry

> "One Drop" — a note about a hot sauce bottle holding a single drop, counted twice by the fridge's inventory.

## Run

```sh
node main.ts
```

Writes the note to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
